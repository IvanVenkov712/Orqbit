# Orqbit tutorials

Choose a guide and follow its numbered steps. The tutorials are in English.

| Tutorial | Who it is for | What you will do |
| --- | --- | --- |
| [Your first job with Orqbit](getting-started/README.md) | New users | Install Orqbit, create an account, register and run workers, submit jobs, and read results. Includes screenshots. |
| [Build a worker with leases and heartbeats](worker-leases-and-heartbeats/README.md) | Readers comfortable editing a little Python | Build an independent worker, renew its execution lease, stop safely when ownership is uncertain, and test the behavior without waiting in real time. |
| [Build an independent producer](build-a-producer/README.md) | Readers comfortable editing a little Python | Build a CLI producer with its own configuration, HTTP requests, submission keys, bounded result polling, and tests. |

Start with the first tutorial if you do not yet have Orqbit running.

Already completed the first walkthrough? Its optional pages show how to [register a producer](getting-started/09-register-a-producer.md) and [run the supplied producer](getting-started/10-start-your-producer.md) without writing code.
